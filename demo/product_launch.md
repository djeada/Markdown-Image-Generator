# Introducing Arcline — Ship Docs That Sell

## The Problem

- Engineering teams waste **12+ hours per week** writing and formatting docs
- Product docs live in wikis nobody reads
- Onboarding guides go stale before the next hire starts
- Marketing and engineering can never agree on a single source of truth

## What Arcline Does

- **Auto-generates** API documentation from your codebase
- Produces **beautiful, branded** pages — no design skills required
- Keeps docs **in sync** with every pull request via CI/CD integration
- Supports Markdown, OpenAPI, and GraphQL schemas out of the box

## Feature Highlights

- **Live Preview** — see changes rendered in real time as you write
- **Version Control** — every doc revision is tracked and diffable
- **Role-Based Access** — control who can view, edit, and publish
- **Custom Domains** — host docs on `docs.yourcompany.com` with one click
- **Search & Analytics** — know exactly what users search for and where they drop off
